과수원과학 교무실 처음 열기 안내

1. 열 때 누를 것
   - "과수원과학 교무실 최종(크롬)" 바로가기를 더블클릭하세요.
   - 주소창에 직접 127.0.0.1을 치는 것보다 이 바로가기로 여는 것이 안전합니다.

2. 지우면 안 되는 것
   - data 폴더
   - assets 폴더
   - index.html
   - app.js
   - styles.css
   - office-server.py
   - run-office-chrome.bat
   - 과수원과학 교무실 최종(크롬).lnk
   - 학생명단-복구백업.json
   - 과수원과학-교무실-최종본.json

3. 학생/반정보 저장 위치
   - 실제 최신 데이터는 data 폴더 안의 office-state.json에 저장됩니다.
   - 저장 전 직전 정상본은 data 폴더 안의 office-state-last-good.json으로 자동 보관됩니다.

4. 예전 파일 위치
   - Netlify용 파일, 옛날 HTML, 중복 바로가기는 "예전파일_보관" 폴더에 옮겨두었습니다.
   - 당장 사용할 필요는 없지만, 혹시 몰라 삭제하지 않고 보관했습니다.

5. 앞으로 수정할 때
   - 학생명단은 학생관리 화면에서만 추가/수정하세요.
   - 반 시간, 수강료, 교재는 반관리 화면에서 수정하세요.
   - 수정 후에는 사이트 안의 자료 백업 버튼도 가끔 눌러두면 더 안전합니다.
   - "백업 파일 불러오기(기존 유지)"는 예전에 저장한 백업 파일을 고를 때만 사용합니다.
